CONEXÃO LOCAL

Seu Telegram, sua sala de aula.

Uma única conexão com sua conta atende os cursos da biblioteca. Escolha o curso no menu e sincronize suas aulas.

  1. Abra conectar.bat

    Na pasta do sistema, execute o arquivo. Ele prepara as bibliotecas e abre a configuração.

  2. Informe as credenciais do Telegram

    Obtenha seu API ID e API Hash em my.telegram.org/apps ↗. Informe os dados somente no terminal local.

  3. Entre na sua conta

    Use seu telefone e o código enviado pelo Telegram. Se houver senha de duas etapas, ela será solicitada. A conta será reutilizada pelos cursos da biblioteca.

  4. Sincronize e comece

    Execute iniciar.bat, volte à sala e clique em Sincronizar Telegram. Apenas os metadados são importados; os vídeos chegam sob demanda.

O Telegram Desktop aberto não fornece a sessão para este servidor. O login local é separado. A pasta data guarda sua sessão e seu progresso; mantenha-a privada.
